# 流派「残響」 — 連作の生成アートの宣言

（algorithmic-art スキルの手順どおり、先に流派の思想を書き、それを `game.src.html` の `RYUHA.zankyo` で生成プログラムとして表している。）

## 思想

一戦は消えない。扇を振った場所、立ち止まった場所、輪を描いて閉じた場所は、墨が引いたあとも紙の繊維に残る。残響は、その痕跡だけを拾い上げて一枚に定着させる流派である。描くのは戦いの絵ではなく、戦いが紙に残した**圧**である。

筆圧は速さの逆数として現れる。速く駆け抜けた道は、筆が紙をかすめただけの細い掠れになり、立ち止まり、踏みとどまって戦った場所ほど墨は深く沈み、やがて紙を塞ぐ闇になる。まっすぐ走り抜けた長い一続きは、藍の水脈として紙を横切る。線の太さ、濃さ、途切れ方はすべて記録から決まり、描き手の手癖は一切入らない。同じ一戦からは何度描いても同じ一枚が生まれ、違う一戦からは決して同じ一枚は生まれない。

筆で囲んだ輪は円相として描き直される。円相は閉じきらない。ひと筆で描かれ、最後の数十度だけが開いている。その開きが次の一戦の入口になり、円の内側には、そのとき還した色が淡く満ちる。墨を最も多く祓った場所には墨はねが散り、そこに次の墨溜まりが眠る。傷を負った場所には朱が点り、次に還せば身を癒やす場所になる。大墨が崩れた場所には渦が残る。

色は前の一戦から受け継がれる。最もよく還した色の系統が紙のにじみの主調になり、二番手、三番手の色がそれを囲む。だから連作を重ねるほど、画帖は描き手の色へと偏っていく。それは描き手の癖であり、次の一戦で育つ色の力の偏りでもある。

この流派の生成は、何度も描き直して整えた職人の仕事として見えなければならない。紙の繊維、にじみの縁の揺らぎ、掠れの途切れ、円相の入りと抜き——どれもが長い時間をかけて調整された末の必然に見えること。そして描かれた一枚は、そのまま次の戦場として遊べること。絵として美しく、場として歩けること。その両立が残響の技である。

## 記録から絵への対応

| 一戦の記録 | 絵の上 | 次のステージでは |
|---|---|---|
| 歩いた道（速さ） | 速いほど細い掠れ、遅いほど深い墨 | 深い墨は通れない闇 |
| まっすぐ走り抜けた長い道 | 藍の水脈 | 水（鈍足・墨が溶ける） |
| まっすぐな道の次点 | 太い筆の一画（途切れあり） | 闇の壁（途切れから通れる） |
| 筆で囲んだ大きな輪 | 円相と、その内側の淡い色 | 名所（入口は円相の開き） |
| 墨を多く祓った場所 | 墨はね | 墨溜まり |
| 傷を負った場所 | 朱の点 | 朱（還すと回復） |
| 大墨が崩れた場所 | 渦 | ― |
| 一戦が終わった場所 | ― | 次の開始位置 |
| 最もよく還した色 | にじみの主調 | 育ちやすい色の力 |
